# Challenge 04 – LOOPLAB

## Algorithm

1. Start.
2. Declare the required variables and initialize totals and counters to 0.
3. Read the expense amount.
4. If the expense is negative, display an invalid input message.
5. If the expense is positive, increment the valid count and add it to the total.
6. If the expense is below 100, increment the Small count and update the Small total.
7. Else if the expense is below 500, increment the Medium count and update the Medium total.
8. Otherwise, increment the Large count and update the Large total.
9. Repeat until the user enters 0.
10. Display the valid expense count, total expenses, and count and total of each category.
11. If the valid count is greater than 0, calculate and display the average.
12. Otherwise, display a message that the average cannot be calculated.
13. Stop.

# Challenge 03 – SMARTCART

## Algorithm

1. Start.
2. Declare the required variables.
3. Read the purchase amount.
4. Read the customer type (1 for Student, 2 for Regular Customer).
5. Read the delivery distance in kilometres.
6. Determine the discount percentage based on customer type and purchase amount using conditional statements.
7. Calculate the discount amount.
8. Calculate the amount after discount.
9. Determine the delivery charge based on the delivery distance using conditional statements.
10. Calculate the final payable amount by adding the delivery charge to the amount after discount.
11. Display the purchase amount, discount amount, amount after discount, delivery charge, and final payable amount.
12. Stop.

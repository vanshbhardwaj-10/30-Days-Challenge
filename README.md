# 30-Day C Programming Challenge

This repository contains my work for the 30-Day C Programming Challenge as part of CSE 101 – Fundamentals of Computing and C Programming.

The challenge is focused on building strong programming fundamentals through regular problem-solving and hands-on C programming practice.

## Challenge Structure

- 2 challenges are assigned each week.
- Each challenge involves understanding the problem, writing an algorithm, developing a C program, testing it, and documenting the results.
- All challenges are maintained in this repository.
- Each challenge has its own folder containing the C program, algorithm/README, and relevant test results.
